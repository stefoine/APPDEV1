# JavaScript Explanation Skill

Use this skill when reviewing beginner JavaScript code.

1. Read the JavaScript file first.
2. Identify the main concept being demonstrated.
3. Explain the important lines in simple language.
4. Point out anything that may be confusing to a beginner.
5. Give a short summary of what the code demonstrates.
6. Keep the explanation focused on the selected file.
